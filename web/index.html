How MyString stores data

The class has two private data members: char* str and int len. There is no std::string inside.

class MyString {
private:
    char* str;
    int len;
    ...
};
  • str points to dynamically allocated character memory (new char[len + 1]).
  • len stores the string length, not counting the terminator.
  • '\0' terminates the character array so stream output can stop at the end.
  • That buffer lives on the heap until the destructor calls delete[] str.

Rule of Three

Because MyString owns a heap buffer, it must define a copy constructor, copy assignment operator, and destructor. Otherwise copies would share one pointer and delete[] would run twice.

1. Copy constructor

MyString a("Hello");
MyString b = a;
MyString::MyString(const MyString& other) {
    len = other.len;
    str = new char[len + 1];
    for (int i = 0; i < len; i++) {
        str[i] = other.str[i];
    }
    str[len] = '\0';
}

2. Copy assignment

MyString a("Hello");
MyString b("World");
b = a;
MyString& MyString::operator=(const MyString& other) {
    if (this == &other) {
        return *this;
    }
    char* newStr = new char[other.len + 1];
    for (int i = 0; i < other.len; i++) {
        newStr[i] = other.str[i];
    }
    newStr[other.len] = '\0';
    delete[] str;
    str = newStr;
    len = other.len;
    return *this;
}

3. Destructor

MyString::~MyString() {
    delete[] str;
}

Operator explorer

These are the operations the assignment requires. Each example runs the same WebAssembly module.

operator+

Allocates a new buffer of length len + other.len + 1, copies both sides, then constructs a result MyString.

MyString c = a + b;
MyString MyString::operator+(const MyString& other) {
    int newLen = len + other.len;
    char* buffer = new char[newLen + 1];
    for (int i = 0; i < len; i++) {
        buffer[i] = str[i];
    }
    for (int i = 0; i < other.len; i++) {
        buffer[len + i] = other.str[i];
    }
    buffer[newLen] = '\0';
    MyString result(buffer);
    delete[] buffer;
    return result;
}

operator==

Compares lengths first, then each character. Returns true only when both buffers match.

bool same = (a == b);
bool MyString::operator==(const MyString& other) {
    if (len != other.len) {
        return false;
    }
    for (int i = 0; i < len; i++) {
        if (str[i] != other.str[i]) {
            return false;
        }
    }
    return true;
}

operator[]

Returns a char&, so c[0] = 'Y' writes into that object’s own buffer.

char ch = a[1];
c[0] = 'Y';
char& MyString::operator[](int index) {
    return str[index];
}

The original implementation does not bounds-check. This page validates the index in JavaScript before calling C++.

operator<< and operator>>

Output writes s.str to a stream. Input reads a whitespace-delimited word into a stack buffer, frees the old heap buffer, and allocates a new one. That is the real cin >> a / cout << a behavior, using istringstream / ostringstream in the browser.

std::ostream& operator<<(std::ostream& out, const MyString& s) {
    out << s.str;
    return out;
}

std::istream& operator>>(std::istream& in, MyString& s) {
    char buffer[1000];
    in >> buffer;
    delete[] s.str;
    s.len = s.getLen(buffer);
    s.str = new char[s.len + 1];
    for (int i = 0; i < s.len; i++) {
        s.str[i] = buffer[i];
    }
    s.str[s.len] = '\0';
    return in;
}

length()

Returns the stored len member. It does not walk the buffer each time.

int n = a.length();
int MyString::length() {
    return len;
}
